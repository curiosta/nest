# Self-hosted fonts (P27)

Latin subset, variable woff2, copied from Google Fonts on 24 Oct 2026 so the site no longer calls fonts.googleapis.com or fonts.gstatic.com
(faster first paint, no third-party request, no layout shift: styles.css pairs each face with a size-adjusted local fallback).

| File | Family | Licence |
|---|---|---|
| fraunces-latin.woff2, fraunces-italic-latin.woff2 | Fraunces (400-600, italic 500) | SIL OFL 1.1, OFL-Fraunces.txt |
| inter-latin.woff2 | Inter (400-800) | SIL OFL 1.1, OFL-Inter.txt |
| jetbrainsmono-latin.woff2 | JetBrains Mono (500-700) | SIL OFL 1.1, OFL-JetBrainsMono.txt |

The site is English only, so Latin glyphs are enough. The fonts are unmodified.
