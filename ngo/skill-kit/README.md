# Rural Tech Lab skill kit

A free, open Agent Skill from NEST Collective (nest.curiosta.com) for NGOs,
schools and Gram Panchayats in India that want to start a hands-on rural
technology lab based on the Vigyan Ashram model (DBRT or IBT).

Guide on the web: https://nest.curiosta.com/ngo/

## Use it
1. **Agents that support Agent Skills:** copy the `rural-tech-lab/` folder into
   your agent's skills folder.
2. **Any other chat agent:** upload `SKILL.md` and the references and templates
   you need, then ask it to follow SKILL.md and start with the intake questions.
3. **No agent:** read SKILL.md, then work through the references and fill in
   the templates.

## Files
- `SKILL.md`: the skill, ending in stop-and-ask-a-human points.
- `references/`: routes (DBRT, IBT, launch checklist), space, tools and safety,
  instructors and RPL, funding routes, compliance, evidence and economics,
  sources.
- `templates/`: asset map, tool inventory, risk assessment, service log,
  instructor roster, KPI tracker, lab committee charter, funding tracker,
  parent consent and safeguarding.
